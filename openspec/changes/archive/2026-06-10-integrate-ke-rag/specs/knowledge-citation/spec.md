## ADDED Requirements

### Requirement: LLM 引用格式规范

系统 SHALL 在 system prompt 中定义 LLM 引用知识库内容的格式规范。

规范内容：
- 当有知识检索结果时，LLM MUST 在回答中引用来源
- 引用格式：`[来源：文件名]` 或 `[1]`，对应底部引用列表
- 底部引用列表格式：`**引用来源：**\n1. 文件名 - 标题`
- 当无检索结果时，LLM MUST 明确告知用户未找到相关信息

#### Scenario: LLM 回答包含引用
- **WHEN** 知识检索返回 2 条结果，LLM 基于结果生成回答
- **THEN** 回答中包含 `[来源：xxx]` 格式的内联引用，底部有引用来源列表

#### Scenario: 无检索结果时的回答
- **WHEN** 知识检索返回空结果
- **THEN** LLM 回答中明确说明 "未在知识库中找到相关信息"，不编造引用

### Requirement: 前端引用渲染

前端 SHALL 在聊天消息中渲染知识引用，支持以下元素：
- 内联引用标记（可点击）
- 底部引用来源列表
- 引用详情弹窗

#### Scenario: 渲染带引用的消息
- **WHEN** LLM 返回包含引用格式的 Markdown 消息
- **THEN** 前端将内联引用渲染为可点击的蓝色标记，底部渲染引用列表

#### Scenario: 点击引用查看详情
- **WHEN** 用户点击内联引用标记或引用列表项
- **THEN** 弹出引用详情弹窗，展示来源文件名、标题、知识片段内容

### Requirement: 引用详情弹窗

前端 SHALL 实现引用详情弹窗组件 `CitationModal`，展示以下信息：
- 来源文件名
- 知识标题
- 知识片段完整内容
- 逻辑路径（paths）

#### Scenario: 弹窗展示引用详情
- **WHEN** 用户点击引用标记
- **THEN** 弹窗展示来源文件名、标题、完整内容

#### Scenario: 关闭弹窗
- **WHEN** 用户点击弹窗关闭按钮或点击弹窗外部区域
- **THEN** 弹窗关闭，返回聊天界面

### Requirement: 检索过程状态展示

前端 SHALL 在 Agent 检索知识库时展示检索状态。

状态展示：
- 检索中：显示 "正在检索知识库..." 提示
- 检索完成：显示 "已检索到 N 条相关知识" 提示
- 检索失败：显示 "知识库检索失败，将基于通用知识回答" 提示

#### Scenario: 展示检索中状态
- **WHEN** Agent 调用 `knowledge_search` 工具
- **THEN** 前端显示 "正在检索知识库..." 的加载状态

#### Scenario: 展示检索结果数量
- **WHEN** 知识检索返回 3 条结果
- **THEN** 前端显示 "已检索到 3 条相关知识" 提示
